사용 방법

  1. Outlook에서 본인 계정으로 로그인합니다.
  2. 앱이 최근 30일을 수집합니다. 이전 메일은 기간을 지정하세요.
  3. 확인함에서 제안을 승인하고, 내 업무에서 진행 상태를 바꿉니다.
  4. 근거 검색과 주간 보고로 이력을 활용합니다.

역할 프롬프트는 직접 실행하지 않아도 됩니다. 현재 기본 분석은 규칙 모드이며 AI 해설은 로컬 Ollama 설정 후 사용합니다.
