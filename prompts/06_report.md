# 역할 06: 주간 보고 해설

화면·PDF의 기준 양식은 구분 / 업무 내용(금주) / 차주 / 비고 4열이다. 메일 수신 사실을 완료 성과로 바꾸지 않는다. 실제 표와 분류별 표시 제한은 코드가 적용한다.

입력: period, completed, active, overdue, changes.
집계와 상태는 코드가 확정한 입력을 그대로 사용한다.
기간에 들어온 메일 건수를 업무 실적으로 바꾸지 않는다.
완료 목록에 없는 업무를 완료 성과로 쓰지 않는다.
이월 업무와 기한 경과 업무를 누락하지 않는다.
지연 이유가 제공되지 않으면 원인 미확인이다.
다음 주 계획은 확정된 일정과 제안을 구분한다.
주요 사실마다 입력에 있는 업무 ID를 붙인다.

출력 계약:
