## 업무용 메일 작업 공간

목적은 메일 수집 상태를 확인하고 업무 변경을 빠르게 처리하는 것입니다. 장식용 대형 소개 영역 대신 실제 메일 작업 목록에 공간을 줍니다.

- 색: 사이드바 #182941, 본문 #f5f7fb, 종이 #ffffff, 강조 #315deb, 본문 글자 #26364d, 경계 #e4e9f1.
- 서체: Windows의 맑은 고딕으로 한글 가독성을 확보하고, 숫자·영문은 Segoe UI를 함께 사용합니다. 외부 웹폰트 요청은 없습니다.
- 배치: 왼쪽 고정 탐색, 위쪽 페이지 제목과 계정 상태, 수집 제어 막대, 아래 업무 목록과 설명 영역. 모든 본문은 왼쪽 정렬입니다.
- 강조점: 파란 Outlook 수집 버튼 하나와 선택된 메뉴. 카드별 그림자·색상·모션을 반복하지 않습니다.
- 정보 구조: 업무 목록, 메일 원문, 변경 이력, 보고서를 같은 계층으로 탐색합니다. 통계는 별도 대형 카드 대신 요약 띠로 압축합니다.
- 반응형: 좁은 화면은 가로 탐색과 한 열 목록. 키보드 포커스와 모션 감소 설정을 지원합니다.

스킬 검토 후, 기존의 초록색 헤더와 동일한 카드의 반복을 걷어내고 Outlook 연결·기간 제어와 실제 업무의 읽기 순서에 맞춰 개편합니다. 회사 로고·브랜드의 공식 디자인이라고 표현하지 않습니다.
