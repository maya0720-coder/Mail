## 빠른 시작

Python 3.11 이상을 설치한 Windows에서 PowerShell을 엽니다.

```powershell
cd D:\99.GPT\02.Mail
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item config.example.json config.json
.\.venv\Scripts\python.exe app.py serve
```

브라우저에서 <http://127.0.0.1:18765>를 여세요. `run.bat`으로도 시작할 수 있습니다. 현재 PC에는 가상환경과 Outlook 의존 패키지를 준비했습니다. 기존 설정이 있으면 복사 명령을 생략하세요.

실제 메일과 분리한 실습은 `.\.venv\Scripts\python.exe app.py --config config.demo.json serve`로 실행하고 <http://127.0.0.1:18766>을 여세요. **사용 방법·가져오기 → 가상 메일 추가**에서 시작합니다.

현재 작업 PC에는 `.venv`를 생성해 두었습니다. 이 PC에서는 `run.bat` 또는 `.\.venv\Scripts\python.exe app.py serve`로 바로 실행할 수 있습니다. 다른 PC로 옮기면 가상환경을 새로 만드세요.

`config.json`이 없으면 예제 설정을 읽습니다. 기본 설정의 `identity_mode=windows_ad`는 Windows 계정명을 사용합니다. 수동 주소를 사용하려면 `identity_mode=manual`, `user_email=실제주소`로 함께 변경하고 별도 데이터 폴더를 지정하세요.

## 제공 기능

- 수집: EML/JSON 가져오기, Classic Outlook 본인 계정, 그룹웨어 브라우저 수집 어댑터.
- 분석: 기본 규칙 기반 실습 모드, 선택적 로컬 Ollama 분석 모드.
- 업무: 신규·변경·취소·완료 제안 확인, 사용자 승인, 기한과 상태 수정.
- 이력: 원문 보관, 업무 이벤트, 실행 단계와 프롬프트 해시 기록.
- 검색: 키워드와 관련 스레드 확장, 업무 변경 이력 조회.
- 업무 히스토리: 로컬 청크 색인·BM25 검색증강·토픽 확장·일자별 근거. Ollama 선택 시 생성형 답변.
- 보고: 기간 종료 시점의 상태 복원, 완료·진행·지연 집계, Markdown 다운로드.
- 토픽: 같은 대화의 메일과 후보를 펼쳐 확인, 최신 수신일순 정렬, 원문 보기 유지.
- PDF 보고: 구분·금주·차주·비고 4열 양식, 근거 링크 포함.
- 위키: 현재 프로젝트 업무 목록과 선택적 AI 해설 생성.

## 중요한 구현 범위

그룹웨어 수집은 **사이트별 선택자를 설정하는 어댑터**입니다. 모든 그룹웨어에 즉시 연결되는 범용 제품은 아닙니다. 실제 회사 화면·계정은 제공되지 않았으므로 실서버 연결은 검증하지 않았습니다.

Classic Outlook은 COM 로컬 객체로 읽습니다. New Outlook은 이 방식의 대상이 아닙니다. New Outlook 사용자에게는 그룹웨어/Outlook 웹 화면에 맞춘 브라우저 어댑터 또는 EML 가져오기를 제공합니다.

**프롬프트 파일을 직접 실행할 필요는 없습니다.** Python 앱이 단계에 맞춰 자동으로 읽습니다. 기본 `rules` 모드는 결정 규칙이고, 실제 AI 의미 분석은 `engine=ollama`와 로컬 모델 설정 후 동작합니다.

기본 규칙 모드는 학습용으로 `업무: ...;`와 ISO 날짜에 맞춰져 있습니다. 자유 형식 메일의 의미 분석은 로컬 Ollama를 켜고 검증해야 합니다. 현재 검색은 임베딩 기반 RAG·GraphRAG가 아닌 키워드+스레드 확장입니다.
